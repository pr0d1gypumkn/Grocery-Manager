# Grocery Manager

A SwiftUI grocery, inventory, and recipe manager using SwiftData and MVVM.

## Step 1

The initial project includes:

- SwiftUI iOS app target
- SwiftData model container
- `StorageLocation`, `Ingredient`, `Recipe`, and `RecipeIngredient` models
- Relationships and cascade-delete rules for location and recipe children
- Minimal runnable root view

Open `GroceryManager.xcodeproj` in Xcode 27 or later. The deployment target is iOS 17.0.
